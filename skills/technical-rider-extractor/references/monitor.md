# Monitor

Use this reference when extracting monitor, IEM, and personal monitoring requirements from a technical rider.

## Extract

Identify and preserve:

- monitor console
- monitor engineer requirements
- monitor mixes
- wedges
- sidefills
- drum fill
- wired IEM
- wireless IEM
- personal monitoring systems
- cue / listen systems
- talkback requirements

## Monitor Mixes

For each mix, capture when available:

- mix number or name
- performer / position
- mono or stereo
- monitoring method
- quantity
- notes

Monitoring methods may include:

- wedge
- IEM
- headphones
- personal monitor mixer
- other dedicated monitor output

Do not assume one performer equals one mix.

Do not assume stereo IEM unless explicitly stated.

## Wedges

Capture:

- quantity
- manufacturer
- model
- performer / stage position
- number of mixes
- additional requirements

Distinguish between:

- standard wedges
- drum fill
- sidefills
- cue / listen wedge

## IEM

Capture:

- wired or wireless
- quantity
- manufacturer
- model
- frequency range when specified
- mono or stereo
- performer / mix assignment
- whether the artist supplies the system
- whether local production must supply the system

Preserve requirements related to:

- transmitters
- bodypack receivers
- wired headphone amplifiers
- antennas
- antenna distribution
- RF coordination
- frequency ranges

Treat RF requirements as explicit requirements only when stated in the rider.

## Personal Monitoring Systems

Capture personal monitoring systems separately from IEM systems.

Examples include:

- Behringer P16
- Aviom
- Allen & Heath ME
- Midas DP48

Capture when available:

- manufacturer
- system / model
- quantity of personal mixers
- performer assignment
- distribution hub or interface
- connection method
- input channel count
- required supporting infrastructure
- whether the artist supplies the system
- whether local production must supply the system

Supporting infrastructure may include:

- Behringer P16-I
- Behringer P16-D
- Ultranet
- Aviom A-Net distributors
- Allen & Heath ME-U
- network or distribution hardware
- compatible stageboxes or digital interfaces

Do not classify a personal monitor mixer as an IEM system.

A personal monitoring system and the device used to listen to it are separate requirements.

For example:

`P16 mixer feeding wired IEM`

contains both:

- personal monitoring system
- wired IEM / headphone output

## Monitor Console

Capture when specified:

- manufacturer
- model
- minimum input requirements
- minimum output / bus requirements
- stagebox requirements
- split requirements
- whether the artist supplies the console
- whether local production must supply the console
- gain-control requirements

Do not infer that a console is suitable or unsuitable unless the task explicitly asks for technical evaluation.

## Signal Split

When specified, capture requirements related to:

- analog split
- digital split
- transformer-isolated split
- stagebox
- digital audio transport
- shared or independent preamp gain
- gain ownership between FOH and monitors

Do not assume FOH and monitors share gain control.

## Artist-Supplied vs Local Production

Preserve clearly who is responsible for providing each monitoring component.

Distinguish between:

- artist supplied
- local production supplied
- venue supplied
- unspecified

Do not assume responsibility based on common touring practice.

## Preferences and Alternatives

Preserve distinctions between:

- required
- preferred
- acceptable
- alternative
- optional

Example:

`Shure PSM1000 preferred, Sennheiser G4 acceptable`

must preserve:

- preferred: Shure PSM1000
- acceptable alternative: Sennheiser G4

Do not treat them as equivalent options.

## Stage Plot

Use the stage plot as supporting information for:

- wedge positions
- performer assignments
- sidefills
- drum fill
- IEM positions
- personal monitor mixers

Do not automatically treat every monitor symbol shown on a stage plot as a confirmed requirement.

## Conflicts

Flag conflicts between:

- monitor section
- equipment list
- input list
- patch sheet
- stage plot

Examples include:

- different monitor mix counts
- wedge vs IEM inconsistencies
- different IEM quantities
- conflicting performer assignments
- different console requirements

Do not resolve conflicts by assumption.

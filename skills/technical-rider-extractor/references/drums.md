# Drums

A complete drum set is divided into:

- Shells
- Hardware
- Cymbals

Use the relevant reference depending on the requirement:

- Shells: [shells.md](shells.md)
- Hardware: [hardware.md](hardware.md)
- Cymbals: [cymbals.md](cymbals.md)

## General Rules

- Extract only explicitly stated requirements.
- Do not infer missing specifications.
- Preserve quantity, size, type, manufacturer, model, and notes.
- Preserve required / preferred / acceptable / optional distinctions.
- Flag conflicts or ambiguous information.
